## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed

### Installation & Development
```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Production Build
```bash
npm run build
npm start
```
